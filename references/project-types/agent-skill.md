# AGENT_SKILL Router

## Route and source priority

Recommend workflow, AI/agent design, information boundaries, decisions, validation, evolution, ownership, risks, and (when real-use evidence exists) outcomes. Inspect `SKILL.md`/metadata first; then references, templates, scripts, tests, examples, changelog/history, and testimony. UI, database, and deployment modules are only likely N/A after inspection.

## Missing facts and false assumptions

Ask about trigger, expected output, routing, context policy, human gates, failure/degradation, real use, and ownership/AI assistance. Do not infer provider, RAG, autonomy, adoption, quality improvement, or authorship from package files. This router selects investigation priorities; it is not a fixed output template.
