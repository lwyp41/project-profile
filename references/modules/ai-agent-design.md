# AI and Agent Design

## Goal

Recover routing, instructions, tools, context sources, deterministic components, human review, evaluation, and safety/privacy boundaries.

## Applicability and depth

Enable for LLM, prompt, agent, automation, or AI-assisted work. Missing model detail is unknown, not N/A.

- **Brief:** inspect primary instruction, metadata, and one execution path.
- **Standard:** inspect conditional references, tools/scripts, examples, tests, context boundaries, and human gates.
- **Deep:** trace routing criteria, progressive disclosure, degradation, evaluation, privacy/cost constraints, deterministic checks, and relevant history.

## Facts, interview, and rendering

Record task, route, instruction/reference, tool, context source, gate, deterministic check, claim type, and caveat. Ask what runtime behavior is configured, what remains user-controlled, and what proves quality. Do not infer RAG, monitoring, model identity, autonomy, or quality improvement; describe mechanisms as mechanisms.

## Render by depth

- **Brief render:** task, primary route, and main tool or instruction boundary.
- **Standard render:** preserve Brief; add routing, context source, tools, deterministic component, human gate, and one safety/cost/quality boundary where evidenced.
- **Deep render:** preserve Standard; add routing criteria, progressive disclosure, degradation behavior, evaluation design, privacy/cost constraints, deterministic checks, and material history or unresolved gaps where evidenced.
