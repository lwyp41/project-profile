# Decisions — Deep

- [choice] The profile is rendered only after a Review gate.
- [context] The workflow must avoid unsupported downstream claims.
- [constraint] Evidence discipline restricts every consequential claim.
- [consequence] Final prose carries evidence states and caveats forward.
- [rationale_gap] A missing supported reason is visible rather than inferred.
- [serious_alternatives] An unattended run is an explicit exception to the normal Review gate.
- [supported_rationale] Review before prose lets the user correct material evidence interpretation.
- [later_validation] Validation checks the profile contract before completion.
- [revision] User corrections can revise the fact model before rendering.
- [conflict] Conflicting facts remain visible rather than being reconciled by assertion.
- [clarification_required] Missing user-answerable rationale is raised as `CLARIFICATION_REQUIRED`.
