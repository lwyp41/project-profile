# Architecture — Standard

- [boundary] The system boundary separates the profile workflow from repository evidence.
- [runtime] A deterministic validator is the visible runtime entry point.
- [core_components] Instructions, references, and validator form the core components.
- [component_relationships] The Skill routes work to references and then the validator.
- [data_flow] Facts move from sources into the profile ledger.
- [interfaces] The Markdown profile and YAML configuration are supported interfaces.
- [constraint] Evidence states constrain what can be rendered as fact.
- [limitation] Validation cannot establish adoption or quality outcomes.
